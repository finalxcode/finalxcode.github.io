# 副业文案自查工具（免费 · 浏览器本地运行）

两个纯前端小工具，无后端、无追踪、不上传输入内容。

- `adlaw-checker/` 广告法违禁词检测：9 类风险词（极限词、国家级背书、绝对化/保证、收益承诺、教育培训、医疗功效、诱导紧迫、站外导流、平台敏感），每条带依据条文与替换建议。
  - 能识别**否定语境**：像「不提供躺赚话术」「不是保收益」「躺赚是不可能的」这类免责表述不会被标红，并在结果里显示忽略了几处。
  - 命中词若落在链接里（URL 中的数字串）不会误判成手机号。
  - 词库在 `words.js`，可自行增删。
- `fee-calculator/` 副业平台到账计算器：知识星球、闲鱼、小红书店铺、抖音小店、公众号流量主、公众号赞赏、微信支付商户。每个费率标注来源链接、核实日期与核实状态；未核实的费率不给默认值，需按后台填写。

打开 `index.html` 即可使用，也可以直接双击本地文件（`file://`）运行。

声明：参考工具，不构成法律意见；平台规则以官方最新公告为准。
