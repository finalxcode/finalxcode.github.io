副业实验周报生成器

每天只记三行数字：投入多少分钟、花了多少现金、到账多少。周末点一下，变成一份能复盘的周报。只做算术，不预测你能赚多少；数据存在你自己的浏览器里，不上传。

1. 填这一周

收入和支出都填实际到账/实际付出去的钱。没到账的意向不要算收入。练习周收入填 0 是正常的。

日期实验标签投入(分钟)支出(元)收入(元)

2. 这周发生了什么（选填）

一行一件。写事实，不写感想：「发了 3 篇，最高阅读 240」「闲鱼下架 1 次，原因是标题」。
